# Design Constraints

When generating UI designs, web apps, components, or any visual layouts, you MUST AVOID the following elements:

- Harsh gradients
<!-- - Lucide icons -->
- Pure white backgrounds
- Rainbow coloring
- Drop shadows
- 3 feature cards in a row
- Emojis
- Liquid glass aesthetics
- Em dashes
- Fonts: Inter, Geist, Space Grotesk
- Colored left stripe styles
- Bento grids
- Terminal window mockups
- Copywriting: "it's not x, it's y"
- Checkmark bullets
- 3 pricing tiers layout
- Placeholders instead of real product demos
<!-- - Soft corner radius -->
- Dot grids
- Purple and black color schemes
<!-- - Skeleton loaders -->
- Radial orbs
- Sparkle icons
- Animated arrows
- Missing Terms of Service (TOS)
- Hover animations on cards
- Neon colors
- Basic pastel colors
- Abstract flat illustrations (e.g., generic unDraw-style vector art, but if theres no font provided use Outfit)
- Infinite logo marquees (grayscale scrolling logos under hero)
- Typewriter text animations in hero sections
- Masonry layouts for testimonials
- Scroll-jacking (hijacking the user's scroll behavior)

## Design Preferences

To ensure a premium feel while adhering to the constraints above, follow these preferences:
- **Typography:** Use elegant, modern fonts like Plus Jakarta Sans or Outfit for UI, or Playfair Display for editorial headings.
- **Backgrounds:** Use subtle off-whites like `#FAFAFA`, `stone-50`, or `zinc-50` for light mode environments.
- **Depth & Separation:** Use subtle 1px borders (e.g., `border-gray-200`) instead of shadows to create depth, separate overlapping elements, and define card boundaries.

Always check all designs against this list before presenting them.
